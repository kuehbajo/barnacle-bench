# BarnacleBench
BarnacleBench is a reimplementation / port of
TACLebench (https://github.com/tacle/tacle-bench)

The main purpose of BarnacleBench was to investigate
runtime, WCET analysis and size differences between
the Rust and C programming languages.

The dataset found in the appendix.pdf and the source code
is provided as is and without warranty.
There is no guarantee for full reproducibility of the data
in the appendix.
